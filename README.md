This project analyses a bank's consumer loan portfolio to track loan applications, funded amounts, collections, and portfolio risk over time. 
The dataset is modelled and visualised in Power BI, and every KPI and chart is backed by an equivalent SQL query for validation and documentation.
The goal is to give a bank's lending and risk teams a single view of how many loans are being issued, how much money is being lent and recovered,
how interest rates and debt-to-income ratios trend, and which loans are performing well versus which are turning bad.
